# Changelog

## v1.5

- Rebranded the project as **EQL Inventory Cleaner** to support future cleanup tools.
- Existing Merge Finder settings migrate automatically to the new settings folder.
- Added persistent **Hide Sky turn-ins** filter.
- Sky filter applies to Confirmed Merges and Possible +0 Duplicates.
- Uses an EQL-specific curated Plane of Sky turn-in list.
- Retains the persistent **Hide already +10** filter.

## v1.4

- Added persistent **Hide already +10** filter.

## v1.3

- Added remembered last inventory file and browse folder.
- Added automatic rescan of the remembered file when it still exists.
- Added remembered window size, theme, report folder, and settings.
- Refreshed the UI with dark/light themes and a more modern layout.

## v1.2

- Added explicit clean shutdown handling for KDE/Wayland/Bazzite.
- Added `Ctrl+Q` close shortcut.

## v1.1

- Initial portable Bazzite-oriented GUI build.

## Repository packaging

- Added MIT license for public distribution.
- Added GitHub-ready README with a real application screenshot.
- Added contribution guidance and issue/pull-request templates.
- Added automated tagged GitHub Release creation for Windows/Linux binaries.
